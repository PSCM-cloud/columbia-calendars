# Columbia venue calendars

Automatically refreshed calendar feeds for the public event listings at Columbia Theater and Columbiahalle in Berlin.

- [Columbia Theater calendar](https://raw.githubusercontent.com/PSCM-cloud/columbia-calendars/main/theater.ics)
- [Columbiahalle calendar](https://raw.githubusercontent.com/PSCM-cloud/columbia-calendars/main/halle.ics)

The feeds update daily using GitHub Actions. Cancelled and relocated events are excluded where the venue pages identify them.
